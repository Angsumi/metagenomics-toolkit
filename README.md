# metagenomics-toolkit

**Status: planning.** Easier metagenomics analysis for researchers who are not full-time bioinformaticians, as both a command-line tool and a desktop/web GUI.

Website: https://tools.angsumi.online/

## Goals
- One command (or one window) from raw reads to an annotated report: quality control, profiling, diversity and figures.
- Sensible defaults with every parameter, tool version and reference recorded, so results can be rerun.
- The same engine behind the CLI and the GUI.

## Planned scope
- Amplicon (16S, 18S, ITS) and shotgun inputs.
- Built on established tools (for example QIIME 2, DADA2, Kraken 2, MetaPhlAn) rather than reimplementing them.
- Plain-language report with methods text ready for a manuscript.
